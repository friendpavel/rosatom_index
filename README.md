# Индекс деловой репутации (Росатом)

Скрипт для консоли браузера (F12) на сайте https://rdr.rosatom.ru/, который извлекает индекс деловой репутации по списку ИНН.

## Использование

1. Откройте https://rdr.rosatom.ru/ в браузере
2. Нажмите F12, перейдите на вкладку Console (Консоль)
3. Вставьте содержимое `console_script.js` и нажмите Enter
4. Результат выведется в консоль

## Формат вывода

```
========== 3662287865 ==========
Наименование:ОБЩЕСТВО С ОГРАНИЧЕННОЙ ОТВЕТСТВЕННОСТЬЮ «ПРОЕКТНО-ИНЖИНИРИНГОВАЯ КОМПАНИЯ САТОМС»
ИНН:3662287865
КПП:366201001
ОГРН:1203600030831
Дата расчёта индекса:22.06.2026 15:00
Запрашиваемая дата:22.06.2026 15:00
Индекс деловой репутации (*10³):
0,607
```

## Настройка

Список ИНН задаётся в массиве `INNS` в начале файла `console_script.js`:

```js
const INNS = ['3662287865', '7706413348'];
```
